# configs/tokenizer

BPE training corpus and artifact settings.

Start with the [outermost AGENTS.md](../../AGENTS.md); it contains the project-wide directory lookup table.

## System design

Hydra YAML here selects or configures runtime components; it does not implement their algorithms. Check defaults order, @package placement, interpolations, _target_ imports, and the final composed config before editing.

## File map

| File(s) | Responsibility |
| --- | --- |
| [nanochat_bpe.yaml](nanochat_bpe.yaml) | Corpus iterator, vocabulary/special-token settings, and output artifact path. |

## Working here

Train via `uv run python src/tools/train_tokenizer.py +tokenizer=nanochat_bpe`; incompatible ID changes require coordinated dataset/checkpoint handling.

Validate composition with `uv run pytest tests/integration/test_config_loading.py`; use component tests for behavior changes.
